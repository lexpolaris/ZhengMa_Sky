# 郑码天空（ZhengMa Sky） QT 版

用 **Qt 6 + C++17** 重写的跨平台郑码训练软件。

> 关于原版郑码天空的训练算法与设计理念，见 [`docs/design.md`](docs/design.md)。

---

## 本版本特点

- **跨平台**：Linux / Windows / macOS 同一套代码，Qt 6 原生渲染，不再依赖 Win32 / VCL。
- **逻辑与界面分离**：训练算法集中在无界面类（`UnitSession` / `SpeedTracker` / `QuestionPool` / `Judge`）中，界面只负责展示与输入，便于测试与复用。
- **题库改用紧凑文本**：静态题库从 XML 改为 TSV（`data/train.txt`），体积约为原来的 1/3，便于手工维护与 diff；解析器同时兼容旧版 XML。
- **数据全明文**：用户数据、题库、帮助文件均为 UTF-8 明文，可直接查看与编辑。
- **训练进度持久化**：每题速度表、等级、积分、连对都会写回 `user.xml`，跨会话/换单元不丢失。
- **测试曲线**：用 Qt Charts 绘制速度 / 成绩曲线，记录每个单元最近 10 次成绩。
- **中文本地化界面**：完整中文提示与帮助。

## 功能

### 三种模式

- **单元训练**：逐题练习，有效计时（离开不计时），多轮循环直到熟练。
- **单元测试**：秒表计时，分页作答，记录成绩并绘制曲线。
- **游戏闯关**：预留（`QuestionPanel::Mode::Speed`）。

### 单元库

按学习阶段分 5 类、共 41 个单元（从题库读取，不硬编码）：

| 分类 | 单元编号范围 | 说明 |
|------|-------------|------|
| 字根单元 | `0`、`2`、`10~19` | 笔画、主根、副根、全部字根 |
| 简码单元 | `20~34` | 一级/二级/三级简码及组合 |
| 词汇单元 | `50~53` | 二字/三字/四字/多字词 |
| 常用单元 | `100~105` | 常用字/词、冠军字、核心字词 |
| 提速单元 | `200~207` | 按基根数分类的字词 |

### 参数设置

- **显示方式**：大写 / 小写
- **末位训练数量**：每轮题数
- **末位训练次数**：自动 / 手动
- **测试题目数量**：自动 / 手动（手动时覆盖默认值）

### 测试记录

- 每个单元保留最近 10 次记录
- 速度 / 击键速度 / 成绩曲线
- 可复制历史到剪贴板

## 数据格式

### `data/train.txt` — 题库（TSV，静态）

制表符分隔，单元头与题目行：

```
# 单元头: @Lib<TAB>LibNo<TAB>LibName<TAB>Count
# 题目行: 字词<TAB>编码<TAB>拆分<TAB>联想
@Lib	0	笔画	24
一	A		横区：A-H
一下	aa avai		组合
```

- 以 `#` 开头为注释，空行忽略。
- 编码可含多个，用空格分隔。
- 解析器同时支持旧版 `Train.xml`（回退），便于迁移。

### `data/user.xml` — 用户数据（运行时读写）

只保存**用户状态**（配置、模式状态、单元进度与速度表），不再重复保存题目：

```xml
<ZmSoft StatusName='Train' DisplayType='0' LastLibNo='0' LastMode='0' ...>
  <Train LibName='笔画' Xp='30' Streak='...' .../>
  <Test  LibName='笔画' .../>
  <Libs>
    <Lib LibName='笔画' LibNo='0' Count='24' Used='0'>
      <SpeedTable>
        <s i='0' v='320'/>   <!-- 第 0 题速度 320ms -->
      </SpeedTable>
    </Lib>
  </Libs>
</ZmSoft>
```

速度表**只写非零项**，压缩存储。

### `data/zmmb.txt` — 码表

`字/词` + Tab + `编码`，多编码以空格分隔：

```
一	a
一下	aa avai
一丘之貉	apwp
…………
```

### `data/zmzg.ttf` — 字根字体（原版）

用于显示标准字体无法渲染的郑码字根。

### `data/help.txt` / `data/UnitHelp.txt` — 帮助（原版）

XML 格式：主帮助与单元说明。

### `data/test_history.xml` — 测试记录（运行时生成）

## 编译

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

依赖：

- **Qt 6.5+**（Widgets、Xml、Charts）
- **CMake 3.16+**
- **C++17 编译器**（GCC 9+ / Clang 10+ / MSVC 2019+）

构建后 `data/` 会自动复制到可执行文件同目录。

## 已知限制

- **热键注册**：全局热键主要在 Windows 上生效，Linux / macOS 需额外配置。该功能并非软件运行必要，暂未实现。
- **多用户**：暂未实现原版的 `user0 / user1 / …` 多档案。
- **游戏模式**：界面已预留，逻辑尚未完成。
